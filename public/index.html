THE ORIGINAL RESEARCH

Retrieve. Ground. Answer.

The rewritten Python backend embeds PDF passages with all-MiniLM-L6-v2 and searches a normalized FAISS IndexFlatIP index. It retrieves six candidates, removes exact duplicates, and keeps three passages.

The notebook baseline uses 1,000-character chunks and 200-character overlap, preserving physical PDF page numbers. Groq can generate structured answers; FLAN-T5 is an optional historical baseline.

THIS WEB APPLICATION

Useful from the first question.

The hosted fallback uses BM25 over the same PDF chunks and is labelled explicitly. A connected Python backend provides MiniLM + FAISS semantic retrieval. Without a generator, the app displays source excerpts.

Groq responses must pass the notebook’s source-ID and verbatim-quote checks. Insufficient evidence and conflicting policies have separate outcomes. Quote checks establish source presence, not factual entailment.

Know what’s behind the answer

01

Traceable

Source cards point back to physical PDF pages and stable chunk IDs. Open the source PDF to review context.

02

Bounded

Unsupported questions are referred to library staff. The app has no live library-system access.

03

Transparent

Older and pandemic-era policies remain source material, rather than being presented as verified current policy.

Academic prototype by team PewPewPew. This is not an official JRU library service. Conversations are saved only in this browser; when Groq mode is enabled, submitted questions and retrieved passages are sent to Groq to generate a response.
