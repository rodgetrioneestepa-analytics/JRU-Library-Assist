A web companion to the PewPewPew Library-Assist RAG chatbot experiment for José Rizal University library FAQs.

THE ORIGINAL RESEARCH

Retrieve. Ground. Answer.

The original notebook embeds the library FAQ collection with all-MiniLM-L6-v2, retrieves passages from ChromaDB, and asks Groq’s openai/gpt-oss-20b model to answer with evidence.

Its default configuration B uses 800-character chunks, 100-character overlap, and three retrieved passages.

FAQ workbook›Retrieval›Cited answer
THIS WEB APPLICATION

Useful from the first question.

FAQ mode uses lightweight BM25 keyword retrieval and returns a source excerpt. Add a server-side Groq API key to generate answers from those passages.

For the original semantic pipeline locally, connect the supplied Flask app through the local server bridge. The original notebook is never executed by this website.

Know what’s behind the answer

01

Traceable

Source cards point back to the original FAQ worksheet and row.

02

Bounded

Unsupported questions are referred to library staff. The app has no live library-system access.

03

Transparent

Older and pandemic-era policies remain source material, rather than being presented as verified current policy.

Academic prototype by team PewPewPew. This is not an official JRU library service. Conversations are saved only in this browser; when Groq mode is enabled, submitted questions and retrieved passages are sent to Groq to generate a response.
